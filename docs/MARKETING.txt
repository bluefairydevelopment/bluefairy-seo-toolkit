BLUEFAIRY SEO TOOLKIT (FREE) — MARKETING COPY
=============================================

Source of truth for the FREE half of the pair. The Pro half has its own file at
../bluefairy-seo-toolkit-pro/docs/MARKETING.txt. The feature comparison table
both of them use lives in COMPARISON.md next to this file — do not restate it

3-SENTENCE SUMMARY
------------------

BlueFairy SEO Toolkit gives a WordPress site the two things it cannot do
without — Open Graph tags so shared links render properly, and a paginated XML
sitemap at /sitemap_index.xml so search engines can find every post and page —
and asks you to configure neither. It detects Yoast SEO, Rank Math, SEOPress and
The SEO Framework and pauses its own output automatically, so installing it can
never give you duplicate meta tags. Free, GPL-2.0-or-later, PHP 8.1+, WordPress
6.6+; add BlueFairy SEO Toolkit Pro when you want JSON-LD schema, canonical
management, og:image and the per-post SEO meta box.


POSITIONING
-----------

This is the honest, complete free plugin, not a crippled demo. It does Open
Graph and sitemaps properly and says plainly what it does not do. The upgrade
argument is never "unlock the plugin you already installed" — it is "you now
have the basics; here is the structured data and the image tag you still
don't."

Say "add Pro", never "upgrade to Pro". Pro is an add-on that runs alongside
this plugin. "Upgrade" reads as a replacement and sets up a support ticket
when the customer deactivates the free plugin and everything stops.

SHORT DESCRIPTION (WooCommerce)
-------------------------------

Open Graph tags and a paginated XML sitemap, with nothing to configure. Pauses
itself automatically if Yoast, Rank Math, SEOPress or The SEO Framework is
active, so you can never end up with duplicate tags. Free and GPL.


WHAT THIS PLUGIN DOES NOT DO
----------------------------

State these plainly wherever the plugin is described. They are the upgrade
argument, and hiding them only produces refund requests.

- No og:image. Shared links render as text-only cards.
- No JSON-LD schema markup of any kind.
- No <link rel="canonical"> tag; core's own tag stays as it is.
- No per-post controls — there is no meta box.
- Sitemaps cover posts and pages only, with no taxonomy archives and no image
  extensions.

All five are in Pro. See COMPARISON.md for the full table, and note in
particular that URL cleaning is a FREE feature — do not write it as a Pro one.
